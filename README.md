WebScope

A simple Bash tool for collecting useful public information about websites.

Features

- Website and hostname information
- DNS / IP information
- HTTP/HTTPS status
- Final URL and redirects
- HTTP version
- Response time
- TLS certificate information
- Security headers
- Simple and interactive terminal menu
- Designed for Termux and Linux

Requirements

- Bash
- cURL
- Termux or Linux
- Optional: OpenSSL
- Optional: "nslookup" or "dig"

Installation

git clone https://github.com/X1-starr/WebScope.git
cd WebScope
chmod +x x1.sh

Usage

Run the script:

./x1.sh

Then choose an option from the menu.

Example

WebScope can collect information such as:

Target
Hostname
IP Address
HTTP Status
Final URL
HTTP Version
Response Time
TLS Certificate
Security Headers

Purpose

WebScope is a small learning project focused on Bash scripting, Linux, networking, and public website information gathering.

Use it only on websites and systems you own or have permission to analyze.
